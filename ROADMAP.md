# Roadmap

## V1

- Deterministic local file indexing for Markdown/text notes.
- Ranked search snippets from local fixtures.
- Agent pack export in Markdown and JSON.
- Clear safety boundaries and no hidden network behavior.

## Next

- Config file for include/exclude rules.
- Better section-level indexing.
- Optional persistent manifest search.
- Watch mode hardening across platforms.
- More fixture sets for docs, support runbooks, and agent memory folders.

## Not planned

- Hosted search service.
- Telemetry.
- Credential scanning.
- Automatic publishing of generated packs.
